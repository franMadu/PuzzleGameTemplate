# Dirección de arte de Shouta

Las líneas rosadas de sonrojo en ambas mejillas son un rasgo visual permanente de Shouta. Deben conservarse en todas las expresiones y outfits, tanto existentes como futuros, incluso cuando esté serio, aburrido o somnoliento. Usar el sprite default de mediodía como referencia de estilo. El sonrojo no debe cambiar la emoción solicitada.

Mantener sus rasgos, edad aparente, proporciones, iluminación neutra de mediodía y fondo transparente. Los sprites de conversación muestran al personaje de pie.
